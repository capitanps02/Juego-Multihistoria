# MUIR P0 — Surface protection map

Baseline: `36d3d1b0750b0ded877e55953f223e2de1169a46`

## PROTEGIDO

Visual identity that P1+ must preserve unless the approved MUIR plan explicitly supersedes it:

- dark depth / dark cinematic foundation;
- broad rounded geometry;
- blue as primary interactive emphasis;
- prestige-gold only in moderation;
- narrative/cinematic emphasis over spreadsheet density;
- one shared UI implementation across Web / PlayCanvas / Android offline.

## ADAPTABLE

May be redesigned after P0 PASS while retaining functionality and authority:

- glass/blur treatment;
- mobile hero height/composition;
- generic panels/cards;
- top bar;
- bottom/side navigation responsive treatment;
- information density and spacing;
- typographic scale within readability/accessibility constraints;
- ordering/presentation of already-public fields;
- tutorial placement.

## REEMPLAZABLE

May be removed/replaced when equivalent functionality remains:

- permanently repeated tutorial presentation;
- generic iconography where a coherent replacement exists;
- redundant decorative copy;
- presentation-only imagery that carries no state or action authority.

## Never visual-authority

No visual redesign may change:

- GameSession command semantics;
- PlayerView/public data authority;
- RNG;
- simulation;
- market/contracts/selection;
- narrative outcomes;
- save schema;
- Football Database authority;
- Player Actions authority.
