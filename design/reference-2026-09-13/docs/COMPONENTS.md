# COMPONENT CATALOG

## NavigationRail
Uso: navegación global.
Material: vidrio funcional.
Estado activo: superficie clara + icono azul.
No usar indicadores dorados permanentes.

## TopToolbar
Uso: nombre de vista + contexto + utilidades.
Material: vidrio funcional.
No duplicar información del contenido.

## HeroPlayer
Uso: Inicio / Perfil.
Debe dominar visualmente.
Datos mínimos integrados sobre imagen.

## ContentCard
Uso: noticias, stats, calendario, historial.
Material sólido.
Radio 22–24 px.
Borde mínimo.

## PrimaryButton
Color: azul.
Una acción primaria por contexto.
Texto corto, verbo primero.

## SecondaryButton
Superficie gris translúcida o sólida.
No competir con PrimaryButton.

## DecisionSheet
Material de vidrio funcional sobre cinemática.
Incluye:
- contexto;
- 2–4 DecisionOption.

## DecisionOption
No mostrar resultado futuro.
Selección: azul.
Hover/focus: escala y elevación ligera.

## StatusRing
Uso: forma/estado agregado.
No abusar de gauges.

## ProgressBar
Uso: atributos y simulación.
Radio completo.
Verde: rendimiento.
Azul: acción/progreso.

## Avatar
Retrato circular o cuadrado suave.
Usar imágenes de personajes coherentes.

## NewsFeature
Imagen grande + titular.
No convertir Mundo en una cuadrícula uniforme de cards.

## RelationshipRow
Avatar + nombre + descripción + estado cualitativo.

## SeasonSummaryStat
Número grande + etiqueta.
Agrupar solo 3–5 métricas principales.

## FocusState
Halo azul + escala.
Debe funcionar con mando/teclado.
