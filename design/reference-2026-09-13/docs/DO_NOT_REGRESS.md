# DO NOT REGRESS

Antes de modificar la interfaz, comprobar esta lista.

- [ ] ¿El Inicio sigue teniendo un único CTA dominante?
- [ ] ¿El jugador sigue siendo visualmente más importante que los paneles?
- [ ] ¿La UI de cinemática sigue siendo mínima?
- [ ] ¿Las decisiones siguen ocultando consecuencias numéricas?
- [ ] ¿El vidrio está reservado a navegación/controles y no invade todo?
- [ ] ¿Las cards de contenido son calmadas y sólidas?
- [ ] ¿Azul sigue siendo la acción primaria?
- [ ] ¿Dorado sigue siendo un acento, no un sistema de botones?
- [ ] ¿El contenido secundario está detrás de una navegación clara?
- [ ] ¿Se puede entender la pantalla en pocos segundos?
- [ ] ¿La navegación con teclado/mando mantiene un foco inequívoco?
- [ ] ¿Las nuevas pantallas parecen parte del mismo producto?
- [ ] ¿Se evita estética de dashboard SaaS?
- [ ] ¿Se evita estética Football Manager densa?
- [ ] ¿Los assets visuales están pensados para recibir UI y no son simples recortes arbitrarios?
