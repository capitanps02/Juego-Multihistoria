# CINEMATICS UI SPEC

## Regla principal

La cinemática no es un popup. Es un cambio de modo.

Durante vídeo/escena:
- ocultar HUD innecesario;
- mantener controles mínimos;
- proteger el encuadre;
- no generar botones/subtítulos dentro del vídeo si se pueden superponer desde el motor.

## Último frame

Cada vídeo debe terminar con:
- protagonista en pausa o reacción;
- movimiento mínimo;
- espacio negativo para UI;
- historia sin resolver.

## Decision sheet

Aparece después o durante el último segundo.
Contiene:
- frase contextual de una línea;
- 2–4 opciones;
- ninguna predicción explícita.

## Variación visual de escenas

No empezar todas igual.
Ejemplos:
- traspaso: móvil / pasillo / carpeta;
- partido: túnel;
- lesión: acción física / caída;
- prensa: flashes;
- familia: llegada a casa.

El usuario debe reconocer el tipo de evento en ~2 segundos incluso sin audio.
